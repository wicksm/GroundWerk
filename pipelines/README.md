# pipelines

One YAML file per pipeline, named after it. azdo-terraform.yml is pipeline azdo-terraform, which plans and applies infra/azdo, and templates/ holds steps that more than one pipeline uses. build-image.yml is pipeline build-image, which builds the dev container's image and pushes it to the registry crgroundwerk, where pipelines pull it by its digest (docs/adr/0008). build-groundwerk.yml is pipeline build-groundwerk, which builds each change to main and is main's PR build, from the ci stage template in GroundWerk.PipelineTemplates at a release tag. The app's deploys will extend a template from there too and use path filters, so each app deploys on its own. Builds run `dotnet run build.cs`, which owns compile, test, pack and publish, and check out with `fetchDepth: 0` and `fetchTags: true`, since versions come from git tags (docs/adr/0005).
